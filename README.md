# ADSDB Project

## Environment

Create a `.env` file in the repository root:

```dotenv
MINIO_ENDPOINT=http://127.0.0.1:9000
MINIO_ACCESS_KEY=your_minio_username
MINIO_SECRET_KEY=your_minio_password
XENO_CANTO_API_KEY=your_xeno_canto_api_key
```

## Run the pipeline

From the repository root, use a Python 3.13 environment with FFmpeg on your PATH and MinIO running on port 9000.

```powershell
python -m pip install -r requirements.txt
python -c "from dotenv import load_dotenv; from master_script import main; load_dotenv('.env'); main()"
```

## Run Tasks 1 and 2

After the pipeline finishes, run `python run_tasks.py`. The script opens the menu directly:

```text
MULTI-MODAL TASKS MENU
TASK 1: Same-Modality Similarity Search
  1. Text Search (BGE)
  2. Image Search (CLIP)
  3. Image Search (DINOv2)
  4. Audio Search (YAMNet - requires Xeno-Canto ID)
  5. Audio Search (Google Perch - requires file path)

TASK 2: Multi-Modality Similarity Search
  6. Cross-Modal Search (Text/Image/Audio in CLIP space)

0. Exit

Select an option (0-6):
```

| Option | What to enter |
| --- | --- |
| 1 | A text description when prompted. |
| 2 or 3 | The absolute path to a local image or MinIO path. |
| 4 | The numeric Xeno-canto ID of a recording indexed by YAMNet. |
| 5 | The absolute path to a local WAV file. |
| 6 | Choose `text`, `image` or `audio`, then enter a description or the absolute path to an image or WAV file. |
| 0 | Exit the menu. |

For **YAMNet (option 4)**, open MinIO at `http://localhost:9001` and browse to `trustedzone/xeno_canto/audio/`. Pick a recording and copy `xeno_canto_id` from its JSON metadata, or take the digits after `XC` in its WAV filename. 
For **options 2 & 3, open MinIO at  `http://localhost:9001` and browse to `trustedzone/huggingface_cub200/images/`. Pick an image and copy the path within the bucket  `huggingface_cub200/images/...`

## Run Task 3

After the pipeline finishes, choose one of the following options and run it locally from the repository root.

**Text input** — run the text retrieval script:

```powershell
python task3/rag_retrieval.py --query "A dark brown seabird with long wings and a curved beak"
```

Open [task3_Llava.ipynb](task3/task3_Llava.ipynb) in Colab.

**Audio input** — create `task3/input_audio/` and save your own WAV recording as `task3/input_audio/query.wav`. The repository does not include a sample WAV.

```powershell
python task3/rag_audio_retrieval.py --audio task3/input_audio/query.wav
```

Open [audio_input_exploration.ipynb](task3/audio_input_exploration.ipynb) in Colab.

For either notebook, select a GPU runtime, upload the ZIP generated by the corresponding script in the first cell and run the remaining cells. In the text notebook, choose one prompt option before running the generation cell.
